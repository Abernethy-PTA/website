# How to post agendas, minutes & budget to the website

The website never needs editing for this. It reads straight from two shared
Google Drive folders — **upload a PDF to the right folder and it's on the site.**

## Secretary — agendas & minutes

1. Export the agenda or minutes as a **PDF**
2. Name it by date so files sort in order:
   `2026-09-17 Community Minutes.pdf` · `2026-09-17 Community Agenda.pdf` · `2026-09-03 Board Minutes.pdf`
3. Upload it to the **Agendas & minutes** folder:
   https://drive.google.com/drive/folders/1WcbMtyez-YbiU7YgVy8xs0AAub235Ni2

That's it — the folder is embedded on supportabernethy.org/meetings/ so the file
appears there automatically.

**Once a year (summer):** move last year's files into the **Minutes archive**
folder so the current folder stays short:
https://drive.google.com/drive/folders/1LFitxnr1VXLFdPkbYtfIv_QxPoZtfxAL

## Treasurer — budget & financial reports

1. Export as **PDF**
2. Name it by year or date:
   `2026-27 Approved Budget.pdf` · `2026-09-30 Budget to Actuals.pdf` · `FY26 Annual Report.pdf`
3. Upload it to the **Budgets & financial reports** folder:
   https://drive.google.com/drive/folders/1ZQBs7WNF5vQ3Uc6YZkwuF85OvNTxJ5rQ

The Finance page (supportabernethy.org/finance/) links families straight to that
folder.

## Rules for both

- **Upload into the folder** (don't share files individually) — the folders are
  already set to "Anyone with the link: Viewer," and files inherit that.
- **PDF, not Google Doc** — PDFs can't be accidentally edited and open for
  everyone.
- **Don't change the folders' sharing settings.** If a folder ever becomes
  private, the website links break for families.

## If a file isn't showing up

- Give it a minute and refresh — Drive embeds can lag briefly.
- Check it went into the folder above (not your My Drive or another folder).
- Still stuck? Email the Technology chair.
